# ADR-0001: البنية: مضيف أصيل رقيق، ومنطق قابل للنقل، وتطوير على Linux أولًا

- الحالة: مقبول
- التاريخ: 2026-11-18

## السياق
التطبيق لـWindows، لكنّ معظم التطوير يجري في بيئات Linux سحابية. ويجب أن يعمل على قاعدة البيانات القديمة (Laravel/NativePHP) دون تغيير.

## القرار
- المنطق كلّه في مكتبات `net10.0`: Core وData وCommands.
- `Rakeeza.Desktop` (WPF وWebView2) مضيف رقيق: يحمّل `ui/dist`، ويوصل الجسر، ويطبّق الخدمات الخاصّة بـWindows.
- `Rakeeza.DevHost` يقدّم الأوامر نفسها عبر HTTP، مع بدائل وهمية لخدمات Windows، لتعمل الواجهة واختبارات Playwright على Linux.
- اتّجاه الاعتماد `Core ← Data ← Commands ← (DevHost | Desktop)`، ويفرضه `Rakeeza.Architecture.Tests` بقراءة ملفّات csproj.
- ملفّ الحلّ بصيغة `.slnx` (الافتراضية في .NET 10) بدل `.sln` المذكور في مسودّة الخطّة.

## العواقب
- كلّ ما يمكن اختباره على Linux يُختبر هناك، وما يحتاج Windows محصور ومذكور في `docs/plan.md` (القسم 3).
- أيّ مشروع جديد تحت `src/` يفشل اختبار البنية حتّى تُسجَّل قواعده.
